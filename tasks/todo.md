# 栄養素の表示と食品の入力画面をわかりやすくする

ブランチ fix/nutrient-card-polish、issue #237。iOS だけ。サーバー、web、本番 D1 は触らない。マージ、デプロイ、申請はしない。

## 計画

- [x] 日々のログの「その他の栄養素」の中の「詳しい栄養素」の畳みをやめ、1回開けば全部並ぶようにする。統計も「詳しい栄養素」の畳みをやめる
- [x] リングのカードの文字を、名前、量、基準値に対する割合だけにする。残りの量と月経の有無の注記は出さない
- [x] 食品の入力の栄養成分を、1日の合計や統計と同じく1枚ずつのカードにして画面の地に並べる。食品の詳細も同じ形にする
- [x] 入力できる欄に枠を付ける。計算で出るだけの糖質は枠を付けない。基本情報は項目名を欄の外に出す
- [x] 「成分表から選ぶ」を「似た食品の値を入れる」にする。機能は残す
- [x] 食品の入力の一番下の「0 は本当に 0 のときだけ」の説明を消す
- [x] テストを流し、通った数と落ちた数を見る
- [x] モックの API でサインインした状態をシミュレーターに作り、変更の前後を撮る

## レビュー

- 「成分表」の表示で残っていたのは、食品の入力の「成分表から選ぶ」の欄と、プロフィールのデータの出典の2つ。前者は今の仕組みで唯一、詳しい栄養素を成分表の値で埋める手段なので消さずに言葉を直した。後者は出典の表記なので残し、入力画面の新しい見出しに合わせて説明を直した
- 統計の部品を AX5 で書き出すテストは、全部を1段に並べたことで1枚の高さを超えた。AX5 だけ見出しごとの絵に分けた
