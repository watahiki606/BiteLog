# #155 個人データを BiteLog から体組成計に設定する

公式アプリを開く最後の理由を消す。変えられるようにするのは、身長・生年月日・性別・体型・
着衣やスマホの重さ・ニックネーム・地域設定。

## わかっていること

公式アプリで値を変えて、ご本人の個人データを読み比べた。

| 項目 | タグ | 形 |
|---|---|---|
| ニックネーム | `6a3d` | 5バイト ASCII。余りは 0 |
| 生年月日 | `6a3c` | 2バイト。1899-12-31 からの日数 |
| 身長 | `6a3e` | 2バイト ÷10 |
| 性別 | `6a37` | 男性 `00` / 女性 `01` |
| 体型 | `6a38` | 標準 `00` / アスリート `01` |
| 着衣やスマホの重さ | `604f` | 2バイト ÷100 |
| 地域 | `6a13` | 取扱説明書の5区分の番号。北海道 `00`、東北 `01`、関東〜四国 `02`、九州 `03`、沖縄 `04` |

- 取扱説明書：身長 90.0〜220.0cm 0.5cm 単位、生年月日 1900-01-01 から
- 書き込みは登録のときと同じ形。呼び名を `7e22` にも入れ、末尾に `7e2f 01 00`（ふだんの値）
- 測定せずに `00 01` を送っても応答が返る。書き込むだけの接続で終えられる
- 公式アプリを使っている間は、公式アプリが測るたびに自分の設定で上書きする。それでよいと確認済み

## 順番

1. [x] `TanitaProfile`：読んだフィールドから項目を取り出し、変えた項目だけ差し替えて書き戻す形を作る（テスト先行）
2. [x] `TanitaSession`：読むだけの接続と、読んで書いて読み直す接続（テスト先行）
3. [x] `TanitaScaleConnection`：上の2つを始める入口と、読んだ個人データを渡す口
4. [x] 画面：設定の体組成計から開く。読んでから編集し、書き込む前に変わる項目を並べて確認する
5. [x] 地域とニックネームの文字数は、公式アプリの画面を見てから決める
6. [x] 実機：BiteLog を登録 → 読む → 1項目変えて書く → 読み直しで一致 → 公式アプリで戻す

## レビュー

- 実機で、BiteLog を登録 → 読み込み → ニックネームに1文字足して書き込み → 読み直しで一致 →
  元に戻して書き込み、まで通した。書き込みの接続はどれも、読み直した値が書いた値と一致して終わった
- 公式アプリの選択肢に合わせた。ニックネームは5文字まで、着衣は 0.0〜2.0kg を 0.1kg 刻み
- 公式アプリの地域は都道府県から選ぶが、並びは取扱説明書の5区分の表と同じで、体組成計に入るのは区分の番号
