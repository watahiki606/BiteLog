# 統計ページで栄養素と体組成の関係を見られるようにする

同じ日の値どうしでは、体組成計のブレと栄養素どうしの連動で関係が見えない。
期間中の摂取と前後の変化を組にし、期間と「単独 / 他の栄養素を固定」を切り替えて見られるようにする。

## 順番

1. [x] `bun test` で apps/web の純粋関数をテストできるようにする（依存は増やさない）
2. [x] `lib/relations.ts`：日次→カロリー源（P/F/C/その他、kcal）と記録漏れ・入力ミスの日の除外（テスト先行）
3. [x] 週ごとの集計と、W週の摂取 × 直前W週→直後W週の変化の組（テスト先行）
4. [x] 切片付き回帰と Newey-West の信頼区間（テスト先行。答えが分かっているデータで確かめる）
5. [x] ヒートマップ用の一覧、期間ごとの係数、翌朝の変化、栄養素どうし（テスト先行）
6. [x] `RelationsSection`：ヒートマップと詳細（散布図・期間ごとの係数・翌朝の変化）、栄養素どうしのタブ
7. [x] 統計ページに置く。全期間の日次データを取る
8. [x] ビルド・実画面で確認

## レビュー

- `bun test` 29件。回帰と信頼区間は、合成データで検証した Python 版の実装と同じ値になることを確かめた
- 手元の実データでも Python 版と一致した。全マスの計算は約40ms
- モック API に実データを流して実画面を確認した。ヒートマップ・マスの選択・ホバー表示・詳細の3グラフ・INTAKE タブ
- 値の小さい指標で目盛りが重なっていたので、有効数字で丸めるよう直した
- 管理画面全体がスマホ幅に対応していないため、スマホ幅ではセクション内の横スクロールで見る
