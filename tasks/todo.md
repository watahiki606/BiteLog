# #182 AI食事解析を GPT-6 Luna に移し、プロンプトと送る画像の大きさを直す

gpt-5-mini は 2026-12-11 に提供終了する。実写真20枚の比較で、GPT-6 Luna の none が精度・費用とも上だった。
iOS は 1024px のつもりで約3072px を送っている。プロンプトは古く、人数・皿・商品名・糖質で誤る。

決めたこと: 1個あたり表示は1個分。複数人分の写真は手前の1人分。

## 計画

- [x] Worker: モデル・effort・system/user 分離・detail・新プロンプトを TDD で

## レビュー

- 評価（Luna none、各3回、ラベル7枚の正解表と1人前判定2枚）
  - 旧プロンプト 1024px: ラベル 14/21、1人前 4/6。新プロンプト 1024px: 17/21、6/6
  - 新プロンプト 1536px: ラベル 21/21、1人前 6/6、44円/1000回、2.1秒。2048px 以上は精度が上がらず高い
  - 3072px に detail high: 入力トークン 7545 → 3263。古いアプリの費用に上限がかかる
  - 現行の gpt-5-mini は 162円/1000回、ラベル 18/21。唐揚げを100g分のまま返す誤りが3回とも出た
- iOS は 1536px を指定すると 4608px で描いていた。倍率3の画像は縮めずに送っていた。ピクセルで比べ、倍率1で描くよう直した
- 残る誤り: 納豆巻きを「納豆」、缶ハイボールを「ウイスキー」と名付けることがある。どちらも包装の表記どおりなので、プロンプトでは追わない
