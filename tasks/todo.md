# アプリで食塩相当量と飽和脂肪酸を記録して見られるようにする

設計は `~/research/bitelog-nutrients/design.md` の2-2、5-3と、7章の PR 8。

## 計画

- [x] 目標量のファイル `DietaryReferenceIntakes.json` を、食事摂取基準 2025年版の表の画像から転記する。1歳以上の性別と年齢区分ごと
- [x] 合計は値の分かっている品だけを足し、`NutrientTotals` で品数を数える
- [x] 食品の入力フォームに「その他の栄養素」を足す。空欄は分からないとして送り、直すときは null で戻す
- [x] 写真の解析の結果画面に2つの欄を足し、値の出典を保存する
- [x] 記録の編集、1日の合計、統計に出す。統計はプロフィールがあれば目標量と並べる
- [x] CSV の書き出しの末尾に2列を足す
- [x] リリースノートに足す。2.13 はまだ申請していないので、版は上げない
- [x] テスト、デザインギャラリー、入力フォームと結果画面の実画面

## 振り返り

- PR 4 では、片方でも不明なら合計も不明にする足し算にしていた。それでは食塩の値が1品でも分からない日に合計が消える。サーバーの集計と同じく、分かっている品だけを足して品数を添える形に改めた
- 統計の推移のグラフに食塩を足す件は見送った。値の分からない日で線を切る作りが要る
- 設計では7日と28日の平均を出すことになっていた。統計の画面は期間を選ぶ作りなので、選んだ期間の1日平均にした
- 実画面で、結果画面の分からない欄が「0」と出て、0 と読み違えることが分かった。薄い文字を「不明」にした
- 大きな文字で、名前と値を横に並べると語の途中で折れた。縦に積むようにした
