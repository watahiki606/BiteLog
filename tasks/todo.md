# web で食塩相当量と飽和脂肪酸を入力して見られるようにする

設計は `~/research/bitelog-nutrients/design.md` の5-4と、7章の PR 9。

## 計画

- [x] テストを先に書く。分かっている値だけの合計、食塩の推移、食品の入力欄
- [x] 食品の編集画面に2つの欄を足す。空欄は分からないとして作り、直すときは null を送って戻す
- [x] 食事ログの1日の合計に食塩を足し、値の分からない品があれば品数を添える
- [x] 統計の推移で食塩を選べるようにする。値の分からない日は 0 にせず線を切り、平均は値の分かっている日だけで割る
- [x] 手元の D1 と Worker と web で、編集、食事ログ、統計を開いて確かめる

## 振り返り

- 統計の推移は、点を14日以下のときしか描いていなかった。食塩は値の分かる日がまばらで、前後の無い1日は線にならず何も見えなかった。欠けのある系列では点も描くようにした
- web はプロフィールを持たないので、基準値は出さない
