# #170 個人データを BiteLog で持ち、登録と測定で体組成計へ書く

#155 の画面は、公式アプリで登録済みの個人データを体組成計から読んで直す作りだった。
BiteLog だけで始める人は個人データを入れる場所が無い。公式アプリと同じく、持ち主をアプリにする。

## 順番

1. [x] `TanitaSession`：測る前と登録のときに BiteLog の個人データを書き、こだまが違えば先へ進まない（テスト先行）
2. [x] `TanitaProfile` を端末に保存する。登録は個人データが無ければ始めない
3. [x] 個人データの画面を、つながずに保存するだけのフォームにする。身長・生年月日・性別・地域は選ぶまで未設定
4. [x] 設定の体組成計を「個人データ → 個人キー → 登録」の順にする
5. [x] 読み込みの画面と接続を消す
6. [x] 実機：個人データを入力 → 登録 → 測る

## レビュー

- 実機で、測る前の書き込み・登録のときの書き込み・登録後の測定が通った。書いた値は毎回こだまで一致した
- 個人データ未入力のときは登録ボタンが押せない
