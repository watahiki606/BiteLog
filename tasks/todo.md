# #176 関係の分析を、答えの文で見せる

ヒートマップと3つのグラフは、回帰・信頼区間・期間の取り方を知っている人でないと読めない。
解説で人が判断していた手順をコードに任せ、確かな関係だけを短い文で出す。ヒートマップ・3つのグラフ・INTAKE タブは消す。
PR #177 はまだマージ前なので、同じブランチに積む。

## 画面

```
あなたの記録で見られる傾向

● 炭水化物を多くとった4週間の前後で、体重が増える傾向があります
  ふだんより1日約30g 多いと、+0.4kg ほど

● タンパク質を多くとった4週間の前後で、筋肉量が増える傾向があります
  ふだんより1日約20g 多いと、+0.2kg ほど

ほかの組み合わせでは、はっきりした関係は見られませんでした。
一緒に動いた傾向で、原因とは限りません。運動など、記録していないことの影響も入ります。
```

## 文にする基準

組み合わせは「合計カロリー・P・F・C・その他」×「データのある体組成の指標すべて」。指標は絞らない。

1. **他の栄養素を固定する**: P・F・C・その他は互いを固定した回帰で見る。合計カロリーは単独
2. **2週間と4週間で同じ向き**: 両方の t 値の小さい方を、その組み合わせの強さにする。数週で戻る変化を除くため
3. **摂取をずらしたときより強い**: 摂取だけを12週以上ずらして体組成との関係を壊したデータを作り、
   全組み合わせの強さの最大値を集める。その 99% 点を超えたものだけを文にする。
   組を重ねて作ることによる見かけの強さと、組み合わせの多さによる偶然を、まとめて抑えられる
4. 確かさの順に並べる。最初は5件まで出し、残りは「ほか N 件」で開く

> 計画の時点では「4週間で 99% の信頼区間、8週間で 95%」を Newey-West の補正で判定する予定だった。
> 関係の無い合成データで試すと、6〜9割の人に文が出てしまったため、上の方法に変えた。

関係が見つからないときも「関係が無い」とは書かない。「はっきりした関係は見られませんでした」とする。

## 文の型

- 1行目: 「{栄養素}を多くとった4週間の前後で、{指標}が{増える / 減る}傾向があります」
  - 合計カロリーは「たくさん食べた4週間」、その他は「PFC 以外のカロリーが多い4週間」
- 2行目: 「ふだんより1日約{量} 多いと、{変化} ほど」
  - **ふだん** = その人の4週間平均の、ばらつき1つ分。+100kcal の決め打ちをやめる
  - 量は P・F・C を g、合計カロリーとその他を kcal で出す。g は P・C が kcal を4で、F が9で割って丸める
- 指標名は日本語にする。体重・体脂肪率・筋肉量・筋肉スコア・内臓脂肪レベル・基礎代謝・体内年齢・推定骨量・体水分率

## データが足りないとき

ずらし方が30通り以上取れるまで、つまり約53週分の記録がたまるまでは判定しない。
体組成の指標は、4週間の期間で組が20以上ある指標だけを見る。
足りないときは「食事と体組成の記録があと約 N 週分たまると、傾向を見られます」と出す。
